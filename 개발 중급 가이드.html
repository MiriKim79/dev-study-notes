🚧 아직 업데이트 중입니다#

중급 가이드는 기초 가이드보다 다루는 항목이 아직 적습니다. 지금도 핵심 개념과 실전 예시는 충분히 담겨 있지만, 계속 내용을 넓혀가는 중입니다.

포함 문서#

문서핵심 내용추천 시점
Git·GitHub 중급 가이드interactive rebase, cherry-pick, bisect, GitHub Actions, 브랜치 보호 심화Git 기본 명령이 손에 익은 뒤
프론트엔드 중급 가이드성능 최적화, 상태관리 라이브러리, 렌더링 전략, 테스트, Core Web Vitals화면 하나를 끝까지 만들어본 뒤
백엔드 중급 가이드캐싱, 메시지 큐, N+1 문제, API 버저닝, Rate Limiting, 로깅API 서버 하나를 끝까지 만들어본 뒤
생성형 AI 중급 가이드파인튜닝, 벡터 DB 심화, 프롬프트 체이닝, 비용 최적화, 평가 자동화기초 RAG·Tool Calling을 붙여본 뒤
팀 협업 중급 가이드코드 리뷰 문화, ADR, 기술 부채 관리, 온보딩 문서화여러 명이 함께 개발을 시작한 뒤
테스트 자동화 중급 가이드테스트 피라미드, TDD, Mock/Stub, 커버리지의 함정, 플레이키 테스트테스트 코드를 체계적으로 짜고 싶을 때
CI·CD 중급 가이드CI/CD 개념, GitHub Actions 배포 파이프라인, 배포 전략, 시크릿 관리배포까지 자동화하고 싶을 때
데이터베이스 중급 가이드인덱스 튜닝, 정규화·역정규화, 복제, 샤딩 기초, 백업과 복구데이터가 많아져 조회가 느려질 때
TypeScript 중급 가이드Union/Generic, interface vs type, 유틸리티 타입, 런타임 검증TypeScript를 실전에 활용하고 싶을 때

이 묶음의 전제#

기초 가이드에서 다룬 내용(HTTP, 컴포넌트, Route/Service/Model, add/commit/push, 프롬프트 기본)은 이미 안다고 가정합니다. 여기서는 "어떻게 하는지"보다 "왜 이 방식을 쓰는지, 언제 필요한지"에 집중합니다.

text
기초 가이드
→ 작은 프로젝트를 하나 끝까지 완성 (배포까지)
→ 이 중급 가이드로 실무 문제 하나씩 채우기

모든 장을 순서대로 읽을 필요는 없습니다. 지금 맡은 프로젝트에서 막힌 부분과 관련된 장부터 골라 읽어도 됩니다.
