포함 문서#

문서핵심 내용추천 시점
Git·GitHub 진짜 최소 기초branch·commit·push·PR·merge·pull이 뭔지 5분 만에 감 잡기Git이라는 단어를 오늘 처음 들어봤을 때
팀 개발 시작 가이드요구사항, MVP, API 계약, 환경 설정, 구현, 테스트, 배포, 회고의 전체 순서새 프로젝트 시작 전
프론트엔드 기초 가이드브라우저, HTML/CSS/JS, 상태, 컴포넌트, API, 인증, 테스트, 빌드·배포화면 개발을 시작할 때
백엔드 기초 가이드서버, HTTP/REST, DB, 인증·인가, 보안, 테스트, 운영·배포API·DB 개발을 시작할 때
생성형 AI 기능 개발 기초 가이드LLM API, 프롬프트, RAG, Tool Calling, Agent, 평가, 보안생성형 AI 기능을 붙일 때
Git·GitHub 기초 가이드버전 관리, 브랜치, push/pull, 충돌, PR, merge/rebase프로젝트 시작 전부터 반복 참고
