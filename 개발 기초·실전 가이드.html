나는 어디부터 봐야 하나? — 등급별 시작 기준#

이 사이트는 초급 → 중급 → 고급으로 이어지고, 자격증 대비는 이 흐름과 별개로 언제든 병행할 수 있는 독립 트랙입니다. 아래 체크리스트에서 "익숙하다"에 해당하는 항목이 많은 줄이 지금 나에게 맞는 시작 지점입니다.

단계이런 상태라면 여기부터시작 문서
🔰 초급프로그래밍을 처음 시작했거나, 변수·조건문·반복문 정도만 안다. Git이 뭔지 모른다. 협업 프로젝트를 해본 적이 없다.Git·GitHub 진짜 최소 기초
📈 중급기본 문법은 익혔고 토이 프로젝트·부트캠프 과제 등 간단한 프로젝트를 만들어본 적 있다. add/commit/push는 써봤지만 브랜치 전략이나 협업 워크플로우는 낯설다.개발 중급 가이드
🏔️ 고급실무 또는 실무에 준하는 프로젝트 경험이 1~2년 이상 있다. 기본적인 CI/CD·배포·코드 리뷰 경험이 있고, 더 깊은 설계·운영 지식을 원한다.개발 고급 가이드
🏅 자격증단계와 무관한 별도 트랙이다. 지금 어느 단계에 있든 시험 일정에 맞춰 언제든 병행할 수 있다.자격증 대비

자가진단 체크리스트#

아래 항목 중 "예"가 많은 줄로 시작하면 됩니다. 정확히 한 단계에만 들어맞지 않아도 괜찮습니다 — 걸치는 경우 더 낮은 단계부터 훑어보고 아는 부분은 빠르게 넘기는 편이 안전합니다.

  • 초급 체크: 변수·조건문·반복문·함수를 안다 / Git·GitHub를 써본 적 없다 / 혼자서 작은 프로그램은 짜봤지만 "서비스"를 만들어본 적은 없다 / 협업 프로젝트 경험이 없다.
  • 중급 체크: 화면 하나 또는 API 서버 하나를 끝까지 만들어 배포까지 해봤다 / git add/commit/push/pull은 익숙하지만 rebase·cherry-pick·브랜치 전략은 낯설다 / 여러 명이 함께 코드를 짜본 경험이 아직 많지 않다.
  • 고급 체크: 실무(또는 실무에 준하는) 프로젝트 경험이 1~2년 이상 있다 / CI/CD 파이프라인을 구성하거나 운영해본 적 있다 / 코드 리뷰를 주고받은 경험이 있다 / 트래픽 증가·장애 대응·설계 트레이드오프 같은 주제에 관심이 있다.

체크리스트로 애매하다면 일단 초급 가이드의 목차만 훑어보고, 이미 아는 내용이 절반 이상이면 중급으로, 그마저도 익숙하면 고급으로 건너뛰는 방식을 추천합니다.
