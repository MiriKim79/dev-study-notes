AI 코딩 에이전트 작업 규칙 (AGENTS.md)

  6. 작업 전 확인

이 저장소에서 작업하는 AI 코딩 에이전트를 위한 지침 템플릿입니다. 사람용 상세 규칙은 CONTRIBUTING.md, 기획·명세는 docs/PLANNING.md에 있습니다.

도구마다 AGENTS.md 지원 방식이 다를 수 있습니다. 사용하는 코딩 도구가 이 파일을 자동으로 읽는지 공식 문서를 확인하고, 필요하면 도구 전용 지침 파일에서 명시적으로 참조합니다.

프로젝트 개요#

  • {{프로젝트 한 줄 설명}}. {{팀 인원 구성}}이 {{기간}} 안에 완성하는 프로젝트입니다.
  • 확정 스택: {{언어/프레임워크}} (/{{frontend-dir}}), {{백엔드 스택}} (/{{backend-dir}}), {{DB}}, {{배포 환경}}
  • 모노레포/멀티레포: {{디렉터리 구조}}. 구조가 아직 없다면 스캐폴드 전 단계이므로 임의로 만들지 말고 사용자와 합의합니다.

필수 규칙#

  • 기준 브랜치는 {{develop 등}}입니다. {{main}}에 직접 커밋·push하지 않습니다. hotfix/*만 {{main}}에서 분기합니다.
  • 브랜치 이름: feat|fix|refactor|hotfix/<내용-kebab-case>-#<이슈번호> — 예: feat/social-login-#5
  • 커밋 형식: 머릿말: 설명 (#이슈번호) — 예: Feat: 로그인 기능 구현 (#5) + 머릿말은 첫 글자 대문자: Feat Fix Refactor Style Comment Docs Test Chore Rename Remove (소문자 feat: 금지) + 제목·본문은 {{한글/영어}}로 쓰고, 제목 끝에 마침표를 붙이지 않으며, 본문에는 무엇을 왜 바꿨는지 씁니다.
  • PR은 {{develop}}을 base로 하고(hotfix/*만 {{main}}) 본문에 Closes #이슈번호를 넣습니다. 사람 리뷰 승인 없이 병합하지 않습니다.

분업 경계#

  • /{{frontend-dir}}는 {{담당}} 소유, /{{backend-dir}}는 {{담당}} 소유입니다. 요청받은 작업이 다른 파트 디렉터리 수정을 요구하면 진행 전에 사용자에게 확인합니다.
  • API 명세({{문서 경로}})는 FE/BE 간 계약입니다. 임의로 바꾸지 말고, 변경이 필요하면 사용자에게 알린 뒤 문서 갱신을 함께 합니다.

작업 방식#

  • 새 라이브러리 도입은 팀 합의 사항입니다. 임의로 추가하지 말고 먼저 제안합니다.
  • 시크릿(.env, DB 비밀번호, 클라우드 키)을 커밋하지 않습니다.
  • {{프로젝트 기간}} 일정의 프로젝트입니다. 요청 범위를 넘는 리팩토링이나 구조 변경을 하지 않습니다.

(선택) 도구별 전용 파일#

  • Claude Code를 쓴다면 CLAUDE.md를 만들고 @AGENTS.md 한 줄로 이 파일을 불러오게 합니다. 도구 전용 지침(예: 커스텀 스킬 사용법)만 CLAUDE.md에 추가로 적습니다.
  • 브랜치 생성·커밋/PR 작성을 스킬(슬래시 커맨드)로 자동화하면 규칙 준수가 훨씬 안정적입니다. (예: /new-branch, /commit-pr)

작업 전 확인#

AI 에이전트는 코드를 수정하기 전에 최소한 다음을 확인합니다.

  1. 현재 브랜치
  2. git status
  3. 관련 README/기획/API 문서
  4. 수정 대상 파일과 호출 관계
  5. 기존 테스트 또는 실행 방법

작업 후 확인#

  1. 변경한 파일 목록 확인
  2. 불필요한 포맷 변경·대규모 리팩토링이 섞이지 않았는지 확인
  3. 가능한 테스트·lint·build 실행
  4. API/DB/환경변수 변경 시 문서 반영
  5. 새 시크릿이나 개인정보가 diff에 없는지 확인
  6. 무엇을 검증하지 못했는지 사람에게 명시

절대 하지 말 것#

  • 테스트가 통과했다고 거짓으로 말하지 않기
  • 읽지 않은 파일 내용을 추측해 수정하지 않기
  • 요청 없이 main/develop force push 또는 이력 재작성하지 않기
  • 사용자 승인 없이 운영 데이터 삭제·배포·결제 등 고위험 작업을 실행하지 않기
  • .env나 실제 API Key를 문서·코드·커밋에 넣지 않기
