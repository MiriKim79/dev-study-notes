Claude Code가 이 저장소에서 작업할 때 참고하도록 두는 전용 지침 템플릿입니다.

@AGENTS.md

Claude Code 전용#

  • 프로젝트에서 실제로 설정한 Claude Code 전용 스킬·커맨드가 있다면 여기에 기록합니다. 예: {{브랜치 생성 명령}}, {{커밋·PR 명령}}.
  • 협업 규칙 상세: CONTRIBUTING.md / 기획·API 명세·일정: docs/PLANNING.md

사용 전 수정할 것#

  • 프로젝트에서 실제 사용하는 스킬/커맨드 이름으로 교체
  • 예시 스킬·커맨드는 실제 프로젝트에 존재하는 이름으로 교체하기
  • AGENTS.md와 중복되는 일반 규칙은 여기서 반복하지 않기
  • Claude Code에만 필요한 권한·도구·명령 규칙만 추가

권장 원칙#

text
AGENTS.md
→ 도구에 크게 의존하지 않는 프로젝트 공통 AI 규칙

CLAUDE.md
