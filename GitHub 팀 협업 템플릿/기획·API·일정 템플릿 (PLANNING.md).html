3. 기능 목록과 우선순위#

ID기능설명우선순위담당상태
F-01{{기능}}{{설명}}Must{{담당}}TODO
F-02{{기능}}{{설명}}Should{{담당}}TODO

우선순위 예:

  • Must: 없으면 서비스가 성립하지 않음
  • Should: 중요하지만 일정에 따라 조정 가능
  • Could: 시간이 남으면
  • Won't: 이번 범위에서 제외
