대상: 보안 심화 가이드로 OWASP·인증·인가 개념은 잡았고, 국가기술자격증으로 검증받고 싶은 사람
목적: 정보보안기사·산업기사 시험 범위를 이 사이트의 보안 심화 가이드와 연결해 정리합니다

0. 시작 전에 — 자주 나오는 용어#

보안 심화 가이드에서 다룬 OWASP·XSS·인증/인가·시크릿 관리 개념은 이미 안다고 가정합니다. 여기서는 이 문서에서 새로 나오는 용어만 정리합니다.

용어쉬운 설명
대칭키 암호화암호화와 복호화에 같은 키를 쓰는 방식. 빠르지만 키를 안전하게 전달하는 게 과제
비대칭키(공개키) 암호화암호화용 키(공개키)와 복호화용 키(개인키)가 다른 방식. 키 전달 문제를 해결하지만 느림
해시(Hash)원본을 되돌릴 수 없는 고정 길이 값으로 변환하는 것. 위·변조 확인이나 비밀번호 저장에 씀
방화벽(Firewall)정해진 규칙에 따라 네트워크 트래픽을 허용·차단하는 장비 또는 소프트웨어
IDS/IPS침입을 탐지(IDS)하거나 탐지와 동시에 차단(IPS)하는 시스템
VPN (가상사설망)공개된 인터넷망 위에 암호화된 전용 통로를 만들어 안전하게 통신하는 기술
접근 통제 모델누가 무엇에 접근할 수 있는지 정하는 방식의 이론적 분류(임의적/강제적/역할 기반 등)
디지털 포렌식침해 사고가 발생했을 때 원인과 증거를 과학적으로 분석·수집하는 과정
전자서명문서를 보낸 사람과 위·변조 여부를 암호학적으로 증명하는 서명 방식
버퍼 오버플로우정해진 메모리 공간보다 큰 데이터를 넣어 인접 메모리를 침범·조작하는 공격
DoS/DDoS대량의 요청으로 서비스를 마비시키는 공격(DDoS는 여러 대의 컴퓨터가 동시에 가함)
스니핑/스푸핑스니핑은 데이터를 몰래 훔쳐보는 것, 스푸핑은 다른 대상인 척 속이는 것
위험(Risk)자산·위협·취약점을 곱해서 평가하는, 보안 관리의 핵심 지표

1. 시험 구성#

정보보안기사·산업기사는 국가기술자격으로, 필기와 실기로 나뉩니다. 시행기관은 2022년부터 한국산업인력공단(큐넷)이 아니라 한국방송통신전파진흥원(KCA)이며, 필기는 CBT(컴퓨터 기반 시험)로 응시 기간 내 원하는 날짜·장소를 골라 응시하고, 실기는 필답형(지필 서술형)으로 정해진 날짜에 전국 동시 시행됩니다. 산업기사는 기사와 달리 "정보보안 관리 및 법규" 과목이 빠져 4개 영역만 평가합니다(정확한 과목 구성·응시자격·응시료는 KCA 자격검정 공식 사이트(cq.or.kr) 공고 기준으로 확인).

기사 필기 기준 자주 다뤄지는 영역:

영역다루는 내용이 사이트와 연결
시스템 보안운영체제 보안, 악성코드, 접근 통제—
네트워크 보안방화벽, IDS/IPS, VPN, 네트워크 공격 유형—
애플리케이션 보안웹 취약점(OWASP), 시큐어 코딩보안 심화 가이드 2장
정보보안 일반암호학 기초, 인증 기술보안 심화 가이드 3장
정보보안 관리 및 법규보안 정책, 관련 법·제도, 위험 관리—

2. 영역별 핵심 포인트#

암호학 기초 — 대칭키 vs 비대칭키#

text
대칭키(예: AES): 암호화 키 = 복호화 키 → 빠름, 키를 상대방에게 안전하게 전달하는 게 과제
비대칭키(예: RSA): 공개키로 암호화 → 개인키로만 복호화 가능 → 느리지만 키 전달 문제 해결

기본 상식: 실무에서는 둘을 섞어 씁니다. 비대칭키로 대칭키(세션 키)를 안전하게 교환한 뒤, 실제 데이터는 빠른 대칭키로 암호화합니다. HTTPS(TLS)가 이 방식으로 동작합니다.

해시와 전자서명#

text
해시(Hash): 원본 → 고정 길이 값. 되돌릴 수 없음. 파일이 변조됐는지 확인할 때 씀
전자서명: 문서의 해시값을 보내는 사람의 개인키로 암호화 → 받는 사람이 공개키로 검증
         → "이 문서를 정말 그 사람이 보냈고, 중간에 안 바뀌었다"를 증명

기본 상식: 해시는 암호화가 아닙니다(복호화가 불가능). 비밀번호를 "암호화해서 저장한다"는 표현은 엄밀히는 틀린 말이고, "해시해서 저장한다"가 맞습니다.

시스템 보안 — 악성코드와 공격 기법#

용어의미
바이러스다른 프로그램에 기생해 함께 실행되며 스스로 복제됨
웜(Worm)숙주 프로그램 없이 스스로 네트워크를 통해 퍼짐
트로이 목마정상 프로그램인 척 위장해 몰래 악성 기능을 수행
랜섬웨어파일을 암호화해 못 쓰게 만든 뒤 금품을 요구
버퍼 오버플로우정해진 메모리 공간(버퍼)보다 큰 데이터를 넣어 인접 메모리를 침범·조작하는 공격

네트워크 공격 유형#

공격방식
DoS(서비스 거부)한 곳에서 대량의 요청을 보내 서비스를 마비시킴
DDoS(분산 서비스 거부)여러 대의 컴퓨터(좀비 PC)에서 동시에 DoS 공격을 가함
스니핑(Sniffing)네트워크를 지나가는 데이터를 몰래 훔쳐봄(도청)
스푸핑(Spoofing)다른 사람·시스템인 척 속여서 정보를 가로채거나 접근함

네트워크 보안 장비#

장비역할
방화벽정해진 규칙(IP, 포트)으로 트래픽을 허용/차단
IDS침입 패턴을 탐지해 관리자에게 알림(차단은 안 함)
IPS탐지와 동시에 자동으로 차단까지 수행

접근 통제 모델#

text
임의적 접근 통제(DAC): 자원의 소유자가 접근 권한을 직접 결정
강제적 접근 통제(MAC): 시스템(관리자)이 미리 정한 보안 등급에 따라 접근 통제
역할 기반 접근 통제(RBAC): 사용자가 아니라 역할(role)에 권한을 부여 — 보안 심화 가이드의 최소 권한 원칙과 연결

애플리케이션 보안 — 보안 심화 가이드와 겹치는 부분#

인젝션, XSS, 접근 제어 취약점은 보안 심화 가이드 2장에서 실무 관점으로 이미 다뤘습니다. 시험에서는 여기에 더해 시큐어 코딩 가이드(행정안전부·KISA 발간) 기준 용어(예: "입력 데이터 검증 및 표현" 같은 분류 명칭)로 묻는 경우가 있으니, 실무 개념과 시험 용어를 서로 연결해두는 것이 좋습니다.

위험 관리 — 정보보안 관리의 큰 틀#

text
위험(Risk) = 자산(Asset) × 위협(Threat) × 취약점(Vulnerability)
  • 자산: 보호해야 할 대상(서버, 데이터, 신뢰도 등)
  • 위협: 자산에 해를 끼칠 수 있는 요인(해킹, 자연재해 등)
  • 취약점: 위협이 파고들 수 있는 약점(패치 안 된 서버, 약한 비밀번호 등)

기본 상식: 위험을 줄이려면 세 요소 중 하나라도 줄이면 됩니다 — 자산의 가치를 낮추긴 어려우니 보통 취약점을 보완(패치·설정 강화)하거나, 위협에 대응하는 통제(방화벽 등)를 추가하는 방식으로 접근합니다.

3. 연습문제#

⚠️ 아래 문제는 개념 이해를 돕기 위해 직접 만든 연습문제이며, 실제 정보보안기사·산업기사 기출문제가 아닙니다.

문제 1. 침입을 탐지함과 동시에 자동으로 차단까지 수행하는 시스템은? A) 방화벽 B) IDS C) IPS D) VPN

문제 2. 사용자가 아니라 역할(role)에 권한을 부여하는 접근 통제 모델은? A) DAC B) MAC C) RBAC D) ACL

문제 3. 여러 대의 좀비 PC를 이용해 동시에 대량의 요청을 보내 서비스를 마비시키는 공격은? A) 스니핑 B) 스푸핑 C) DDoS D) 버퍼 오버플로우

문제 4. 위험(Risk)을 구성하는 세 요소가 아닌 것은? A) 자산(Asset) B) 위협(Threat) C) 취약점(Vulnerability) D) 결함(Defect)

정답: 1번 C / 2번 C / 3번 C / 4번 D

4. 실전 연습문제 (정답 클릭 확인)#

⚠️ 이 섹션의 문제는 실제 기출 유형·난이도를 참고해 새로 만든 오리지널 연습문제이며, 실제 기출문제 원문이 아닙니다. 정답을 클릭하면 해설이 펼쳐집니다.

Q1. 침입을 탐지하는 것에 더해 자동으로 차단까지 수행하는 보안 시스템은? A) 방화벽(Firewall) B) IDS(침입탐지시스템) C) IPS(침입방지시스템) D) VPN

정답 보기

정답: C

IDS는 탐지만 하고 관리자에게 알리는 반면, IPS는 탐지와 동시에 자동으로 트래픽을 차단하는 능동적 대응까지 수행합니다.

Q2. 대칭키 암호화와 비대칭키 암호화의 차이로 옳은 것은? A) 대칭키는 암호화·복호화에 서로 다른 키를 쓴다 B) 비대칭키는 암호화·복호화에 같은 키를 쓴다 C) 대칭키는 암호화·복호화에 같은 키를 쓰고, 비대칭키는 공개키·개인키 쌍을 쓴다 D) 두 방식 모두 키가 필요 없다

정답 보기

정답: C

대칭키(예: AES)는 하나의 키로 암·복호화를 모두 수행하고, 비대칭키(예: RSA)는 공개키로 암호화, 개인키로 복호화하는 키 쌍을 사용합니다.

Q3. 사용자 개인이 아닌 '역할(Role)'에 권한을 부여하고 사용자를 그 역할에 배정하는 접근 통제 모델은? A) DAC(임의적 접근 통제) B) MAC(강제적 접근 통제) C) RBAC(역할 기반 접근 통제) D) ACL(접근 통제 목록)

정답 보기

정답: C

RBAC는 사용자에게 직접 권한을 부여하지 않고 역할을 통해 권한을 관리해, 조직 변화 시 역할만 재배정하면 되므로 유지보수가 쉽습니다.

Q4. 여러 대의 좀비 PC(봇넷)를 동원해 동시에 대량 요청을 보내 서비스를 마비시키는 공격은? A) 스니핑(Sniffing) B) 스푸핑(Spoofing) C) DDoS(분산 서비스 거부 공격) D) SQL 인젝션

정답 보기

정답: C

DDoS는 다수의 감염된 시스템(봇넷)을 이용해 동시에 대량 트래픽을 발생시켜 서비스를 마비시키는 공격입니다.

Q5. 위험(Risk) = 자산 × 위협 × 취약점의 관계에서, 각 요소에 대한 설명으로 옳지 않은 것은? A) 자산은 보호해야 할 대상이다 B) 위협은 자산에 손실을 끼칠 수 있는 잠재적 원인이다 C) 취약점은 위협이 이용할 수 있는 약점이다 D) 자산이 없어도 위험은 항상 동일하게 존재한다

정답 보기

정답: D

위험은 자산·위협·취약점이 모두 존재할 때 성립합니다. 보호할 자산이 없다면 위협·취약점이 있어도 실질적 위험은 성립하지 않습니다.

Q6. 웹 애플리케이션에서 악성 스크립트를 게시글 등에 삽입해 다른 사용자의 브라우저에서 실행시키는 공격은? A) XSS(Cross-Site Scripting) B) CSRF(Cross-Site Request Forgery) C) 버퍼 오버플로우 D) 세션 하이재킹

정답 보기

정답: A

XSS는 악성 스크립트를 웹 페이지에 삽입해 다른 사용자의 브라우저에서 실행되게 하는 공격입니다. CSRF는 사용자의 인증 세션을 이용해 의도치 않은 요청을 강제로 전송시키는 공격입니다.

Q7. (OX) 해시 함수는 원문을 복원할 수 없는 일방향(단방향) 함수로, 주로 무결성 검증과 비밀번호 저장에 사용된다.

정답 보기

정답: O

해시 함수는 입력을 고정 길이 값으로 변환하며 역산이 사실상 불가능해, 비밀번호 저장이나 파일 무결성 검증에 사용됩니다.

Q8. (OX) 공개키 기반의 전자서명은 송신자의 공개키로 서명하고 개인키로 검증한다.

정답 보기

정답: X

전자서명은 반대로 송신자의 개인키로 서명하고, 수신자가 송신자의 공개키로 검증합니다. 그래야 개인키를 가진 본인만 서명을 생성할 수 있습니다.

Q9. (단답형) 인증(Authentication)과 인가(Authorization)의 차이를 한 문장으로 구분해서 설명하라.

정답 보기

정답: 인증은 '누구인지 확인'하는 것이고, 인가는 '확인된 사용자에게 어떤 권한을 줄지 결정'하는 것

인증(신원 확인) 이후에 인가(권한 부여)가 이루어지는 것이 일반적인 흐름입니다.

Q10. (단답형) 정보보호의 3대 요소(CIA)를 모두 쓰라.

정답 보기

정답: 기밀성(Confidentiality), 무결성(Integrity), 가용성(Availability)

기밀성은 인가된 사람만 접근 가능, 무결성은 정보가 변조되지 않음, 가용성은 필요할 때 정상적으로 접근 가능함을 의미합니다.

Q11. 네트워크 트래픽을 감시하다가 미리 정의된 공격 패턴(시그니처)과 일치하면 탐지·경고하지만, 자동으로 차단하지는 않는 시스템은? A) 방화벽(Firewall) B) IDS(Intrusion Detection System) C) IPS(Intrusion Prevention System) D) WAF(Web Application Firewall)

정답 보기

정답: B

IDS는 침입을 탐지하고 알리는 역할만 하며, 실제 차단까지 자동으로 수행하는 것은 IPS입니다. 방화벽은 정해진 규칙(포트, IP)에 따라 트래픽을 허용/차단합니다.

Q12. 공개키 암호화 방식에서, 송신자가 자신의 개인키로 서명하고 수신자가 송신자의 공개키로 검증함으로써 얻을 수 있는 보안 목표는? A) 기밀성(Confidentiality)만 B) 부인 방지(Non-repudiation)와 무결성 C) 가용성(Availability) D) 접근 통제(Access Control)

정답 보기

정답: B

전자서명은 개인키로만 생성 가능하므로 "본인이 서명했음"을 부인할 수 없게 하고(부인 방지), 서명값이 원문과 일치하는지 확인해 위변조 여부(무결성)도 검증할 수 있습니다.

Q13. SQL 인젝션 공격을 근본적으로 방어하기 위한 가장 효과적인 코딩 방법은? A) 에러 메시지를 사용자에게 자세히 보여줌 B) 파라미터 바인딩(Prepared Statement)을 사용해 입력값을 쿼리 문자열과 분리 C) 입력값 길이를 제한하지 않음 D) 관리자 계정으로만 쿼리 실행

정답 보기

정답: B

파라미터 바인딩은 사용자 입력을 쿼리 구문과 분리된 값으로 전달해, 입력값이 SQL 명령어로 해석되지 않도록 근본적으로 차단합니다.

Q14. 정보보호 관리체계(ISMS) 인증에서, 위험을 식별·분석·평가한 뒤 수용 가능한 수준으로 낮추기 위한 일련의 활동을 무엇이라 하는가? A) 위험 관리(Risk Management) B) 재해 복구(Disaster Recovery) C) 형상 관리(Configuration Management) D) 변경 관리(Change Management)

정답 보기

정답: A

위험 관리는 자산·위협·취약점을 분석해 위험을 평가하고, 그 결과에 따라 위험을 회피·감소·전가·수용하는 대응 전략을 선택하는 전체 프로세스입니다.

Q15. 무선랜(Wi-Fi) 보안 프로토콜 중 현재 가장 강력한 것으로 권장되는 것은? A) WEP B) WPA C) WPA2 D) WPA3

정답 보기

정답: D

WEP는 이미 취약점이 널리 알려져 사용이 권장되지 않으며, WPA3가 개인/기업 환경 모두에서 현재 가장 강력한 암호화와 인증을 제공하는 최신 표준입니다.

Q16. (OX) 방화벽(Firewall)은 애플리케이션 레벨의 논리적 공격(예: SQL 인젝션, XSS)까지 완벽하게 차단할 수 있다.

정답 보기

정답: X

일반적인 방화벽은 IP·포트 기반으로 트래픽을 허용/차단하는 네트워크 레벨 보안 장비로, 애플리케이션 로직을 이해하지 못해 SQL 인젝션·XSS 같은 애플리케이션 레벨 공격은 WAF(웹 애플리케이션 방화벽) 등 별도 대응이 필요합니다.

Q17. (단답형) 정상 사용자인 것처럼 위장해, 실제로는 정상 트래픽처럼 보이는 대량의 요청을 보내 서버 자원을 소진시키는 공격 중, HTTP GET 요청을 아주 느리게 반복 전송해 커넥션을 계속 점유하는 공격 기법의 이름은?

정답 보기

정답: Slowloris (슬로우로리스) 공격

Slowloris는 HTTP 요청 헤더를 일부러 아주 느리게, 완결되지 않은 상태로 계속 보내 서버의 연결 자원을 오래 점유시켜 다른 정상 사용자의 접속을 막는 애플리케이션 레벨 DoS 공격입니다.

5. 합격 꿀팁#

  • 암기량이 많은 시험입니다. 대칭키/비대칭키, DAC/MAC/RBAC처럼 짝을 이루는 개념은 나만의 비교표로 정리해두면 시험장에서 헷갈리지 않습니다.
  • 보안 심화 가이드에서 다룬 실무 개념(XSS, 인증/인가, 시크릿 관리)과 연결지어 이해하면, 단순 암기보다 훨씬 오래 남습니다.
  • 법·제도 과목은 실무 감각으로 유추하기 어려운 암기 위주 과목입니다. 다른 과목을 어느 정도 정리한 뒤 마지막에 몰아서 암기하는 것이 효율적입니다.

6. 자주 하는 실수#

  • 대칭키/비대칭키의 장단점을 반대로 외움(비대칭키가 빠르다고 착각)
  • IDS와 IPS를 "둘 다 차단한다"고 혼동
  • 접근 통제 모델 3가지의 "누가 권한을 결정하는가" 기준을 헷갈림
  • 실무에서 쓰는 용어(OWASP 등)와 시험 교재 용어(시큐어 코딩 가이드 분류)를 따로 외워서 연결을 못함

7. 실전 체크리스트#

  • 대칭키·비대칭키 암호화의 차이와 실제로 함께 쓰이는 방식(TLS)을 설명할 수 있는가
  • 해시와 전자서명의 차이를 설명할 수 있는가
  • 바이러스·웜·트로이목마·랜섬웨어의 차이를 구분하는가
  • DoS/DDoS, 스니핑/스푸핑을 예시와 함께 구분하는가
  • 방화벽·IDS·IPS의 역할 차이를 구분하는가
  • DAC·MAC·RBAC 세 가지 접근 통제 모델을 구분하는가
  • 위험(Risk) = 자산×위협×취약점 공식과 각 요소의 의미를 아는가
  • 보안 심화 가이드에서 다룬 개념(XSS, 인증/인가)을 시험 용어와 연결해뒀는가
  • 기사/산업기사 중 어느 쪽에 응시 자격이 맞는지 공식 사이트에서 확인했는가

8. 진짜 기출문제는 여기서#

공식 기출문제·시행 공고는 시행기관인 한국방송통신전파진흥원(KCA) 자격검정 사이트(cq.or.kr)에서 확인하세요(2022년부터 한국산업인력공단 큐넷이 아닌 KCA로 시행기관이 이관되었습니다). 사이트 접속 후 정보보안기사·정보보안산업기사 메뉴에서 응시자격·시험과목·기출 관련 자료를 확인할 수 있습니다(정확한 하위 경로는 사이트 개편에 따라 바뀔 수 있어 직접 메뉴를 찾아 들어가는 것을 권장합니다). 이 문서는 시험 범위와 개념 정리만 제공합니다.

text
너는 정보보안기사·산업기사 자격증 출제 전문가야. 아래 조건으로 실전 모의고사를 만들어줘.

10. 자주 헷갈리는 개념 정리#

헷갈리는 짝구분
대칭키 vs 비대칭키 암호화대칭키는 암·복호화에 같은 키 사용(빠름, 키 교환이 과제 — AES), 비대칭키는 공개키/개인키 쌍 사용(느림, 키 교환 문제 해결 — RSA)
암호화 vs 해시암호화는 키로 복호화 가능(양방향), 해시는 원문 복원 불가능(단방향) — 비밀번호는 해시로 저장
IDS vs IPSIDS는 탐지만 하고 알림(Detection), IPS는 탐지 후 즉시 차단까지 수행(Prevention)
방화벽 vs WAF방화벽은 IP·포트 단위로 네트워크 계층 필터링, WAF(Web Application Firewall)는 HTTP 요청 내용(SQL Injection, XSS 패턴 등) 단위로 필터링
DAC vs MAC vs RBACDAC는 자원 소유자가 권한 결정, MAC는 시스템이 정한 보안 등급으로 강제 통제, RBAC는 역할(직무)에 권한을 부여하고 사용자를 역할에 배정
무결성 vs 기밀성 vs 가용성정보보안 3요소(CIA) — 무결성(변경되지 않음), 기밀성(허가된 사람만 접근), 가용성(필요할 때 정상 이용 가능)

11. 시험 직전 최종 점검 리스트#

  • CIA(기밀성·무결성·가용성) 3요소를 각각의 침해 사례와 함께 설명할 수 있는가
  • 대칭키·비대칭키 암호화의 대표 알고리즘(AES, RSA)과 용도를 구분하는가
  • 해시 함수의 특성(충돌 회피성, 역상 저항성)과 활용 예(비밀번호 저장, 무결성 검증)를 아는가
  • SQL Injection, XSS, CSRF의 공격 원리와 방어 방법을 각각 설명할 수 있는가
  • 접근 통제 모델(DAC/MAC/RBAC) 중 상황에 맞는 모델을 고를 수 있는가
  • 위험 관리 절차(자산 식별 → 위협·취약점 분석 → 위험 평가 → 대응)를 순서대로 아는가

12. 암호화·접근통제·위험관리 계산·사례 심화#

이 장은 원리 비교표와, 위험관리 공식을 실제 수치에 적용하는 계산 유형, 접근통제 모델을 사례로 구분하는 문제를 정리합니다. 모두 개념 이해를 위한 오리지널 창작 예제입니다.

12.1 해시 vs 대칭키 vs 비대칭키 원리 비교표#

구분해시(Hash)대칭키 암호화비대칭키 암호화

기본 상식: 셋은 서로 대체재가 아니라 역할이 다른 도구입니다. TLS(HTTPS)에서는 세 가지가 모두 함께 쓰입니다 — 비대칭키로 세션 키를 교환하고(키 교환), 그 세션 키(대칭키)로 실제 데이터를 암호화하며, 데이터가 변조되지 않았는지는 해시(HMAC)로 검증합니다.

12.2 접근통제 모델(DAC/MAC/RBAC) 사례 구분 문제#

예제 문제: 아래 세 가지 상황을 DAC, MAC, RBAC 중 알맞은 모델과 매칭하라.

text
① 회사 인사 시스템에서 "팀장"이라는 직책을 가진 사람에게만 팀원 급여 조회 권한을 부여한다.
   직책이 바뀌면 권한도 자동으로 바뀐다.
② 리눅스에서 파일 소유자가 chmod 명령으로 다른 사용자의 읽기/쓰기 권한을 직접 설정한다.
③ 군사 기밀 문서 시스템에서, 문서마다 "비밀", "대외비" 같은 등급이 매겨져 있고
   사용자도 등급이 있어 시스템이 자동으로 접근 가능 여부를 판단한다. 사용자가 등급을 바꿀 수 없다.

풀이 과정

  1. ①은 "직책(역할)"에 권한을 부여하고 사용자를 그 역할에 배정 → RBAC
  2. ②는 "자원의 소유자"가 직접 권한을 결정 → DAC
  3. ③은 "시스템(관리자)이 정한 등급 규칙"을 사용자가 임의로 바꿀 수 없음 → MAC

정답: ① RBAC, ② DAC, ③ MAC

판별 포인트: "누가 권한을 결정하는가"를 기준으로 삼으면 헷갈리지 않습니다 — 소유자 본인(DAC), 시스템의 고정 등급 규칙(MAC), 역할 정의(RBAC).

12.3 위험관리 공식 적용 문제#

text
위험(Risk) = 자산 가치(Asset) × 위협 발생 가능성(Threat) × 취약점 정도(Vulnerability)

예제 문제: 아래 두 시스템의 위험도를 계산해 어느 쪽이 더 시급한 보안 투자가 필요한지 판단하라. (각 요소는 1~5점 척도로 평가되었다고 가정)

시스템자산 가치위협 발생 가능성취약점 정도
A: 사내 게시판 서버234
B: 고객 결제 시스템532

풀이 과정

text
시스템 A 위험도 = 2 × 3 × 4 = 24
시스템 B 위험도 = 5 × 3 × 2 = 30

정답: 시스템 B(위험도 30)가 시스템 A(위험도 24)보다 위험도가 더 높으므로 우선 보안 투자 대상입니다.

해석: 시스템 A는 취약점이 더 크지만(4 vs 2) 자산 가치가 낮아 전체 위험도는 B보다 낮습니다. 이처럼 위험관리는 취약점 하나만 보지 않고 자산 가치까지 함께 곱해서 우선순위를 정합니다 — 아무리 취약해도 잃을 게 적은 시스템보다, 조금 덜 취약해도 잃을 게 큰 시스템을 먼저 방어하는 것이 합리적입니다.

참고 — 위험 대응 전략 4가지

전략의미예시
회피(Avoidance)위험이 있는 활동 자체를 하지 않음검증 안 된 외부 API 연동을 포기
감소(Mitigation)통제를 추가해 위험을 낮춤패치 적용, 방화벽 설치
전가(Transfer)위험을 제3자에게 넘김보험 가입, 외부 위탁(아웃소싱)
수용(Acceptance)위험이 낮아 그대로 감수발생 가능성·영향이 미미한 위험 방치

12.4 계산·사례 실전 연습 (정답 클릭 확인)#

Q1. 온라인 쇼핑몰에서 "관리자", "일반 회원", "판매자"라는 세 그룹을 만들고 각 그룹에 서로 다른 메뉴 접근 권한을 부여한 뒤, 신규 직원을 "관리자" 그룹에 배정만 하면 권한이 자동으로 적용되는 방식은 어떤 접근통제 모델인가?

정답 보기

정답: RBAC(역할 기반 접근 통제)

개별 사용자가 아닌 역할(그룹)에 권한을 부여하고, 사용자를 역할에 배정하는 방식이 RBAC의 핵심입니다.

Q2. 자산 가치 4점, 위협 발생 가능성 5점, 취약점 정도 3점인 시스템의 위험도는?

정답 보기

정답: 60 (4×5×3)

위험(Risk) = 자산 × 위협 × 취약점 = 4 × 5 × 3 = 60.

Q3. 파일 소유자가 "다른 사용자에게 읽기 권한만 준다"처럼 자신의 판단으로 권한을 직접 부여·회수하는 방식은?

정답 보기

정답: DAC(임의적 접근 통제)

자원의 소유자가 재량으로 접근 권한을 결정하는 것이 DAC의 특징입니다. 유연하지만 소유자의 실수로 과도한 권한이 부여될 위험도 있습니다.

Q4. 대용량 파일을 암호화해서 네트워크로 전송해야 할 때, 속도 문제로 실무에서 선호되는 암호화 방식은?

정답 보기

정답: 대칭키 암호화(예: AES)

대칭키는 비대칭키보다 훨씬 빠르게 동작해 대용량 데이터 암호화에 적합합니다. 다만 이 대칭키 자체를 안전하게 전달하기 위해 비대칭키로 키 교환을 먼저 수행하는 것이 일반적입니다(하이브리드 방식).

Q5. 위험 대응 전략 중, 침해 사고 발생 시 손실을 보전받기 위해 사이버 보험에 가입하는 것은 어떤 전략에 해당하는가?

정답 보기

정답: 전가(Transfer)

위험 자체를 없애거나 줄이는 것이 아니라, 발생 시의 손실 부담을 보험사 등 제3자에게 넘기는 방식이 전가 전략입니다.
