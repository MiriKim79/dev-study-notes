> **대상:** 통계나 데이터 분석을 정식으로 배운 적은 없지만, ADsP(데이터분석 준전문가) 자격증을 준비하는 사람
> **목적:** 한국데이터산업진흥원이 주관하는 ADsP 시험 범위를 다루며, 통계·분석 개념을 시험에 나오는 형태로 정리합니다
> **사용법:** 시험 정보(문항 수, 합격 기준, 접수 일정)는 회차마다 바뀔 수 있으니 이 문서로 개념을 잡은 뒤 반드시 공식 사이트(데이터자격검정 dataq.or.kr)에서 최신 공고를 확인하세요.
> **📝 이 문서는 핵심 요약노트입니다.** 정식 교재를 대체하지 않습니다 — 감을 잡고 복습하는 용도로 쓰고, 실전 대비는 공식 교재와 기출문제로 함께 준비하세요.

# 0. 시작 전에 — 자주 나오는 용어

| 용어 | 쉬운 설명 |
| --- | --- |
| 정형 데이터 | 표(테이블)처럼 행과 열로 딱 떨어지게 정리된 데이터 |
| 비정형 데이터 | 이미지, 영상, 자유 형식 텍스트처럼 정해진 구조가 없는 데이터 |
| 반정형 데이터 | JSON, XML처럼 구조는 있지만 표 형태는 아닌 데이터 |
| 평균(Mean) | 모든 값을 더해 개수로 나눈 대표값 |
| 중앙값(Median) | 값을 크기순으로 줄 세웠을 때 정중앙에 오는 값 |
| 분산(Variance) / 표준편차(Standard Deviation) | 값들이 평균에서 얼마나 흩어져 있는지 나타내는 지표 |
| 상관관계(Correlation) | 두 변수가 함께 움직이는 정도. 상관관계가 있다고 반드시 원인-결과 관계는 아님 |
| 회귀분석(Regression) | 한 변수(들)로 다른 변수의 값을 예측하는 통계 기법 |
| 분류(Classification) | 데이터를 미리 정해진 몇 개의 범주 중 하나로 나누는 것(예: 스팸/정상) |
| 군집분석(Clustering) | 정답 범주 없이, 비슷한 데이터끼리 스스로 그룹을 짓는 것 |
| 과적합(Overfitting) | 모델이 학습 데이터에만 지나치게 맞춰져서, 새로운 데이터에는 오히려 성능이 떨어지는 현상 |
| 결측값(Missing Value) | 데이터에서 값이 비어있는 부분 |
| 이상값(Outlier) | 다른 값들과 동떨어진, 유난히 크거나 작은 값 |
| 귀무가설/대립가설 | 통계 검정에서 "차이가 없다"는 기본 가정(귀무)과 그 반대 주장(대립) |
| p-value | 귀무가설이 맞다고 가정할 때, 지금 결과(또는 더 극단적인 결과)가 우연히 나올 확률 |
| 혼동행렬(Confusion Matrix) | 분류 모델의 예측과 실제 정답을 표로 정리해 성능을 평가하는 방법 |
| 정밀도(Precision) / 재현율(Recall) | 정밀도는 "맞다고 예측한 것 중 진짜 맞은 비율", 재현율은 "진짜 정답 중 놓치지 않고 맞춘 비율" |

# 3. 2과목 핵심 — 분석 기획과 방법론

## CRISP-DM — 데이터 분석 표준 절차

```text
1. 업무 이해(Business Understanding)
2. 데이터 이해(Data Understanding)
3. 데이터 준비(Data Preparation)
4. 모델링(Modeling)
5. 평가(Evaluation)
6. 전개(Deployment)
```

**기본 상식**: 이 6단계는 한 번 쭉 진행하고 끝나는 게 아니라, 앞 단계로 돌아가 반복하는 과정입니다(예: 모델링 중 데이터가 부족하다는 걸 깨달으면 3단계로 되돌아감). 시험에서는 "이 상황은 몇 번째 단계에 해당하는가"를 묻는 식으로 나옵니다.

## 분석 과제 우선순위 — 시급성과 난이도

```text
시급성(지금 당장 필요한가) × 난이도(구현하기 쉬운가)
→ 시급성 높고 난이도 낮은 과제부터 우선 진행하는 것이 일반적 원칙
```

## 분석 마스터플랜(ISP) — 여러 과제의 우선순위를 정하는 큰 그림

개별 분석 과제 하나가 아니라, 조직 전체의 여러 분석 과제를 어떤 순서로 추진할지 정하는 계획입니다. ROI(투자 대비 효과)와 실행 용이성을 함께 고려해 로드맵을 그립니다.

## 하향식 접근법 vs 상향식 접근법

| 접근법 | 방식 | 적합한 경우 |
| --- | --- | --- |
| 하향식(Top-Down) | 문제를 먼저 정의하고, 그 문제를 풀기 위한 데이터를 찾음 | 무엇을 해결해야 하는지 이미 명확할 때 |
| 상향식(Bottom-Up) | 일단 데이터를 탐색하며 패턴을 찾고, 거기서 문제를 발견함 | 문제 정의 자체가 어렵거나 데이터 탐색이 우선일 때 |

**기본 상식**: 실제 분석 프로젝트에서는 두 방식을 오가며(문제 정의 → 데이터 탐색 → 문제 재정의) 진행하는 경우가 많습니다. 시험에서는 "이 상황은 어느 접근법에 가까운가"를 사례로 묻습니다.

# 4. 3과목 핵심 — 통계와 분석 기법

## 대표값과 산포도

```text
평균: [10, 20, 30, 1000] → (10+20+30+1000)/4 = 265 — 극단값(1000)에 크게 흔들림
중앙값: [10, 20, 30, 1000] → 20과 30의 평균인 25 — 극단값 영향이 적음
```

**기본 상식**: 극단값(outlier)이 있는 데이터에서는 평균이 왜곡될 수 있어, 중앙값을 함께 참고합니다. "어느 대표값이 더 적절한가"를 묻는 문제가 자주 나옵니다.

## 데이터 전처리 — 분석 전에 반드시 거치는 단계

```text
결측값(Missing Value) 처리
- 삭제: 결측값이 있는 행/열을 아예 제거 (데이터가 충분히 많을 때)
- 대체: 평균·중앙값·최빈값 등으로 채워 넣기 (데이터를 살리고 싶을 때)

이상값(Outlier) 처리
- 탐지: 박스플롯(사분위수 기준), Z-score(평균에서 몇 표준편차 떨어졌는지) 등으로 발견
- 처리: 제거하거나, 상한/하한값으로 눌러서(capping) 영향력을 줄임
```

**기본 상식**: 이상값이라고 무조건 삭제하지 않습니다. 진짜 오류(입력 실수)인지, 실제로 존재하는 극단적이지만 의미 있는 값(VIP 고객의 초고액 구매 등)인지 먼저 구분해야 합니다.

## 가설검정 기초

```text
귀무가설(H0): "차이가 없다/효과가 없다"는 기본 가정 (예: 새 디자인과 기존 디자인의 클릭률은 같다)
대립가설(H1): 귀무가설과 반대되는, 증명하고 싶은 주장 (예: 새 디자인의 클릭률이 더 높다)

p-value: 귀무가설이 맞다고 가정했을 때, 지금 관측된 결과(또는 더 극단적인 결과)가 나올 확률
→ p-value가 아주 작으면(보통 0.05 미만) "우연이라 보기 어렵다"고 판단해 귀무가설을 기각
```

**기본 상식**: p-value가 작다고 "효과가 크다"는 뜻이 아닙니다. "이 차이가 우연히 생겼을 가능성이 낮다"는 뜻일 뿐입니다. 이 둘을 헷갈리는 게 실무에서도 흔한 오해입니다.

## 분석 기법 큰 그림

| 기법 | 목적 | 예시 |
| --- | --- | --- |
| 회귀분석 | 숫자값 예측 | 광고비로 매출 예측 |
| 분류 | 범주 예측 | 이메일이 스팸인지 아닌지 |
| 군집분석 | 그룹 스스로 나누기 | 비슷한 구매 패턴의 고객 묶기 |
| 연관규칙분석 | 함께 나타나는 패턴 찾기 | "기저귀를 사면 맥주도 산다" |

## 과적합 이해

```text
학습 데이터에서는 정확도 99% → 새 데이터에서는 정확도 60%
→ 모델이 학습 데이터의 노이즈까지 외워버린 상태(과적합)
```

**기본 상식**: 과적합을 막기 위해 데이터를 학습용과 검증용으로 나눠서, 학습에 쓰지 않은 데이터로 성능을 확인하는 것이 기본 원칙입니다.

## 분류 모델 평가 — 혼동행렬(Confusion Matrix)

스팸 메일 분류를 예로 들면, 모델의 예측과 실제 정답을 표로 정리합니다.

```text
                실제 스팸        실제 정상
예측 스팸    TP(맞게 스팸 잡음)   FP(정상을 스팸으로 오판)
예측 정상    FN(스팸을 놓침)      TN(맞게 정상 판정)
```

| 지표 | 계산 | 의미 |
| --- | --- | --- |
| 정확도(Accuracy) | (TP+TN) / 전체 | 전체 중 맞게 예측한 비율 |
| 정밀도(Precision) | TP / (TP+FP) | "스팸이라고 예측한 것" 중 진짜 스팸 비율 |
| 재현율(Recall) | TP / (TP+FN) | "진짜 스팸" 중 놓치지 않고 잡아낸 비율 |

**기본 상식**: 정확도만 보면 안 되는 대표적인 경우가 있습니다. 스팸이 전체의 1%뿐이면, "전부 정상"이라고만 예측해도 정확도는 99%가 나오지만 스팸을 하나도 못 잡습니다(재현율 0%). 어떤 지표를 우선할지는 상황에 따라 다릅니다 — 암 진단처럼 "놓치면 안 되는" 경우는 재현율을, 스팸 필터처럼 "정상을 잘못 거르면 안 되는" 경우는 정밀도를 더 중요하게 봅니다.

# 7. 합격 꿀팁

- **3과목(데이터 분석)에 시간을 가장 많이 투자하세요.** 배점이 가장 큽니다.
- 공식을 외우기보다 "왜 이 지표를 쓰는지" 이해에 집중하세요. ADsP는 계산 문제보다 개념을 묻는 문제 비중이 높습니다.
- 회귀·분류·군집·연관규칙분석처럼 비슷해 보이는 기법들은 "목적이 뭔지"를 기준으로 표를 만들어 비교해두면 헷갈리지 않습니다.
- CRISP-DM은 순서를 외우는 것에서 그치지 말고, "왜 앞 단계로 되돌아갈 수 있는지"까지 이해해두면 응용 문제에도 대응할 수 있습니다.

# 12. 자주 헷갈리는 개념 정리

| 헷갈리는 짝 | 구분 |
| --- | --- |
| 데이터 vs 정보 vs 지식 vs 지혜 | 데이터(가공 전 사실) → 정보(의미 부여) → 지식(정보의 축적·구조화) → 지혜(경험 기반 통찰), DIKW 피라미드 순서로 암기 |
| 정형 vs 반정형 vs 비정형 데이터 | 정형(RDB 테이블), 반정형(XML/JSON, 스키마는 있지만 유연), 비정형(이미지·영상·텍스트) |
| 지도학습 vs 비지도학습 | 지도학습은 정답(레이블) 있음(분류·회귀), 비지도학습은 정답 없이 구조 발견(군집화·연관규칙) |
| 정확도(Accuracy) vs 정밀도(Precision) vs 재현율(Recall) | 정확도는 전체 중 맞춘 비율, 정밀도는 양성으로 예측한 것 중 실제 양성 비율, 재현율은 실제 양성 중 맞춘 비율 |
| 상관분석 vs 회귀분석 | 상관분석은 두 변수의 관계 강도·방향만 파악, 회귀분석은 한 변수로 다른 변수를 예측하는 식을 도출 |
| 1종 오류 vs 2종 오류 | 1종 오류는 귀무가설이 참인데 기각(false positive), 2종 오류는 귀무가설이 거짓인데 채택(false negative) |

# 14. 통계 계산 문제 심화 풀이

> ADsP는 개념 문제 비중이 높지만, 평균·분산·표준편차·상관계수를 손으로 직접 계산하거나 혼동행렬 지표를 계산하는 문제도 매회 출제됩니다. 아래는 풀이 과정을 보여주는 오리지널 창작 예제입니다.

## 13.1 평균·분산·표준편차 손계산

**예제 문제**: 데이터 `{2, 4, 4, 4, 5, 5, 7, 9}`의 평균, 분산, 표준편차를 구하라.

**풀이 과정**

1단계 — 평균 계산
```text
평균(μ) = (2+4+4+4+5+5+7+9) / 8 = 40 / 8 = 5
```

2단계 — 각 값의 편차(값-평균)와 편차 제곱
| 값 | 편차(값-평균) | 편차² |
| --- | --- | --- |
| 2 | -3 | 9 |
| 4 | -1 | 1 |
| 4 | -1 | 1 |
| 4 | -1 | 1 |
| 5 | 0 | 0 |
| 5 | 0 | 0 |
| 7 | 2 | 4 |
| 9 | 4 | 16 |

3단계 — 분산 계산 (모집단 분산 기준: 편차 제곱의 합 ÷ 개수)
```text
편차² 합계 = 9+1+1+1+0+0+4+16 = 32
분산(σ²) = 32 / 8 = 4
```

4단계 — 표준편차 계산 (분산의 제곱근)
```text
표준편차(σ) = √4 = 2
```

**정답**: 평균 5, 분산 4, 표준편차 2

**참고**: 표본 분산을 구할 때는 개수(n)가 아니라 (n-1)로 나눕니다(불편추정량). 이 예제처럼 "모집단 전체"로 명시되면 n으로, "표본"으로 명시되면 (n-1)로 나눈다는 점을 문제 지문에서 확인해야 합니다. 위 예제를 표본 분산으로 계산하면 32/7 ≈ 4.57입니다.

## 13.2 상관계수 손계산

**예제 문제**: 두 변수 X(공부 시간), Y(시험 점수)의 데이터가 아래와 같을 때 상관관계의 방향을 해석하라.

| 학생 | X(시간) | Y(점수) |
| --- | --- | --- |
| A | 1 | 50 |
| B | 2 | 60 |
| C | 3 | 65 |
| D | 4 | 80 |
| E | 5 | 95 |

**풀이 과정 (개념적 절차)**

1. X와 Y 각각의 평균을 구한다: X̄=3, Ȳ=70
2. 각 학생마다 (X-X̄)와 (Y-Ȳ)를 구하고, 두 값을 곱한다(공분산 계산의 재료).
3. (X-X̄)(Y-Ȳ) 값이 대부분 양수(둘 다 평균보다 크거나 둘 다 작음)면 **양의 상관**, 대부분 음수면 **음의 상관**.

| 학생 | X-X̄ | Y-Ȳ | 곱 |
| --- | --- | --- | --- |
| A | -2 | -20 | 40 |
| B | -1 | -10 | 10 |
| C | 0 | -5 | 0 |
| D | 1 | 10 | 10 |
| E | 2 | 25 | 50 |

곱의 합 = 40+10+0+10+50 = 110 (양수) → **X가 커질수록 Y도 커지는 양의 상관관계**입니다. 실제 상관계수는 공분산을 각 변수의 표준편차로 나눠 -1~1 사이로 표준화한 값이며, 이 예제는 부호(방향)만 판단하면 충분한 유형입니다.

**기본 상식**: 상관계수가 1에 가까울수록 강한 양의 선형관계, -1에 가까울수록 강한 음의 선형관계, 0에 가까울수록 선형관계가 거의 없다는 뜻입니다. 단, 상관계수 0은 "선형" 관계가 없다는 것이지 관계 자체가 전혀 없다는 뜻은 아닙니다(U자형 등 비선형 관계는 상관계수가 0에 가까워도 존재할 수 있음).

## 13.3 혼동행렬로 정확도·정밀도·재현율·F1 계산

**예제 문제**: 어떤 스팸 필터가 메일 200통을 검사해 아래와 같은 결과를 냈다. 정확도, 정밀도, 재현율, F1-Score를 계산하라.

| | 실제 스팸 | 실제 정상 |
| --- | --- | --- |
| 예측 스팸 | TP = 40 | FP = 10 |
| 예측 정상 | FN = 20 | TN = 130 |

**풀이 과정**

1단계 — 정확도(Accuracy)
```text
정확도 = (TP+TN) / 전체 = (40+130) / 200 = 170/200 = 0.85 → 85%
```

2단계 — 정밀도(Precision)
```text
정밀도 = TP / (TP+FP) = 40 / (40+10) = 40/50 = 0.80 → 80%
```

3단계 — 재현율(Recall)
```text
재현율 = TP / (TP+FN) = 40 / (40+20) = 40/60 ≈ 0.667 → 약 66.7%
```

4단계 — F1-Score (정밀도와 재현율의 조화평균)
```text
F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)
   = 2 × (0.80 × 0.6667) / (0.80 + 0.6667)
   = 2 × 0.5333 / 1.4667
   ≈ 1.0667 / 1.4667
   ≈ 0.7273 → 약 72.7%
```

**참고**: F1-Score는 조화평균 공식 대신 `F1 = 2×TP / (2×TP+FP+FN)`로 한 번에 계산할 수도 있습니다. 이 예제는 `80 / (80+10+20) = 80/110 ≈ 0.7273`으로 동일한 결과가 나옵니다.

**정답**: 정확도 85%, 정밀도 80%, 재현율 약 66.7%, F1-Score 약 72.7%

**해석**: 재현율(약 66.7%)이 정밀도(80%)보다 낮다는 것은, 이 필터가 "정상 메일을 스팸으로 잘못 거르는 것"보다 "진짜 스팸을 놓치는 것(FN=20)"이 상대적으로 더 많다는 뜻입니다. 스팸 필터의 목적에 따라 어느 지표를 우선할지 판단이 달라집니다.

## 13.4 가설검정 유의수준 판단 문제

**예제 문제**: 새 랜딩페이지 디자인이 기존보다 클릭률이 높은지 검정했더니 p-value = 0.03이 나왔다. 유의수준(α) 0.05를 기준으로 할 때 결론은?

**풀이 과정**

1. 귀무가설(H0): "새 디자인과 기존 디자인의 클릭률은 차이가 없다"
2. 대립가설(H1): "새 디자인의 클릭률이 다르다(또는 더 높다)"
3. 판단 규칙: p-value < α 이면 귀무가설 기각(유의미한 차이로 판단), p-value ≥ α 이면 귀무가설 채택(차이가 있다고 보기 어려움)
4. 0.03 < 0.05 이므로 **귀무가설을 기각** → 두 디자인의 클릭률 차이는 통계적으로 유의미하다고 판단

**정답**: 귀무가설 기각, 통계적으로 유의미한 차이가 있다고 판단한다.

**주의**: 만약 유의수준을 α=0.01로 더 엄격하게 잡았다면 어떻게 될까? 0.03 > 0.01 이므로 이번엔 귀무가설을 **기각하지 못합니다**(차이가 있다고 단정할 수 없음). 같은 p-value라도 유의수준을 어디로 잡느냐에 따라 결론이 달라질 수 있다는 점이 시험에서 자주 출제되는 함정입니다.
