> **대상:** 통계나 데이터 분석을 정식으로 배운 적은 없지만, ADSP(데이터분석 준전문가) 자격증을 준비하는 사람
> **목적:** 한국데이터산업진흥원이 주관하는 ADSP 시험 범위를 다루며, 통계·분석 개념을 시험에 나오는 형태로 정리합니다
> **사용법:** 시험 정보(문항 수, 합격 기준, 접수 일정)는 회차마다 바뀔 수 있으니 이 문서로 개념을 잡은 뒤 반드시 공식 사이트(데이터자격검정 dataq.or.kr)에서 최신 공고를 확인하세요.

# 0. 시작 전에 — 자주 나오는 용어

| 용어 | 쉬운 설명 |
| --- | --- |
| 정형 데이터 | 표(테이블)처럼 행과 열로 딱 떨어지게 정리된 데이터 |
| 비정형 데이터 | 이미지, 영상, 자유 형식 텍스트처럼 정해진 구조가 없는 데이터 |
| 반정형 데이터 | JSON, XML처럼 구조는 있지만 표 형태는 아닌 데이터 |
| 평균(Mean) | 모든 값을 더해 개수로 나눈 대표값 |
| 중앙값(Median) | 값을 크기순으로 줄 세웠을 때 정중앙에 오는 값 |
| 분산(Variance) / 표준편차(Standard Deviation) | 값들이 평균에서 얼마나 흩어져 있는지 나타내는 지표 |
| 상관관계(Correlation) | 두 변수가 함께 움직이는 정도. 상관관계가 있다고 반드시 원인-결과 관계는 아님 |
| 회귀분석(Regression) | 한 변수(들)로 다른 변수의 값을 예측하는 통계 기법 |
| 분류(Classification) | 데이터를 미리 정해진 몇 개의 범주 중 하나로 나누는 것(예: 스팸/정상) |
| 군집분석(Clustering) | 정답 범주 없이, 비슷한 데이터끼리 스스로 그룹을 짓는 것 |
| 과적합(Overfitting) | 모델이 학습 데이터에만 지나치게 맞춰져서, 새로운 데이터에는 오히려 성능이 떨어지는 현상 |

# 1. 시험 구성

ADSP는 3과목으로 나뉩니다.

| 과목 | 다루는 내용 |
| --- | --- |
| 1과목: 데이터 이해 | 데이터의 종류, 데이터베이스 기본 개념, 데이터 사이언스의 이해 |
| 2과목: 데이터 분석 기획 | 분석 프로젝트를 어떻게 기획하고 관리하는지, 분석 방법론 |
| 3과목: 데이터 분석 | 통계 기초, 정형/비정형 데이터 분석 기법 — 배점이 가장 큼 |

객관식이며, **과목별 최소 점수**와 **전체 평균 최소 점수**를 모두 넘겨야 합격입니다(정확한 문항 수·시간은 공식 공고 기준으로 확인).

---

# 2. 1과목 핵심 — 데이터와 데이터 사이언스의 이해

## 데이터 유형 구분

```text
정형: 회원 테이블, 매출 엑셀
반정형: API 응답 JSON, 로그 파일
비정형: 사진, 동영상, 자유 서술형 리뷰 텍스트
```

## 데이터 사이언스의 요구 역량

시험에서 자주 나오는 3요소: **분석적 사고(통계·수학)**, **IT 기술(프로그래밍·엔지니어링)**, **비즈니스 이해(도메인 지식)**. 이 세 가지가 겹치는 영역이 데이터 사이언스의 핵심 역량이라는 개념(다이어그램 형태)이 잘 나옵니다.

# 3. 2과목 핵심 — 분석 기획과 방법론

## CRISP-DM — 데이터 분석 표준 절차

```text
1. 업무 이해(Business Understanding)
2. 데이터 이해(Data Understanding)
3. 데이터 준비(Data Preparation)
4. 모델링(Modeling)
5. 평가(Evaluation)
6. 전개(Deployment)
```

**기본 상식**: 이 6단계는 한 번 쭉 진행하고 끝나는 게 아니라, 앞 단계로 돌아가 반복하는 과정입니다(예: 모델링 중 데이터가 부족하다는 걸 깨달으면 3단계로 되돌아감). 시험에서는 "이 상황은 몇 번째 단계에 해당하는가"를 묻는 식으로 나옵니다.

## 분석 과제 우선순위 — 시급성과 난이도

```text
시급성(지금 당장 필요한가) × 난이도(구현하기 쉬운가)
→ 시급성 높고 난이도 낮은 과제부터 우선 진행하는 것이 일반적 원칙
```

# 4. 3과목 핵심 — 통계와 분석 기법

## 대표값과 산포도

```text
평균: [10, 20, 30, 1000] → (10+20+30+1000)/4 = 265 — 극단값(1000)에 크게 흔들림
중앙값: [10, 20, 30, 1000] → 20과 30의 평균인 25 — 극단값 영향이 적음
```

**기본 상식**: 극단값(outlier)이 있는 데이터에서는 평균이 왜곡될 수 있어, 중앙값을 함께 참고합니다. "어느 대표값이 더 적절한가"를 묻는 문제가 자주 나옵니다.

## 분석 기법 큰 그림

| 기법 | 목적 | 예시 |
| --- | --- | --- |
| 회귀분석 | 숫자값 예측 | 광고비로 매출 예측 |
| 분류 | 범주 예측 | 이메일이 스팸인지 아닌지 |
| 군집분석 | 그룹 스스로 나누기 | 비슷한 구매 패턴의 고객 묶기 |
| 연관규칙분석 | 함께 나타나는 패턴 찾기 | "기저귀를 사면 맥주도 산다" |

## 과적합 이해

```text
학습 데이터에서는 정확도 99% → 새 데이터에서는 정확도 60%
→ 모델이 학습 데이터의 노이즈까지 외워버린 상태(과적합)
```

**기본 상식**: 과적합을 막기 위해 데이터를 학습용과 검증용으로 나눠서, 학습에 쓰지 않은 데이터로 성능을 확인하는 것이 기본 원칙입니다.

# 6. 자주 하는 실수

- 평균과 중앙값의 차이를 상황 없이 공식만 외움
- CRISP-DM을 "한 번에 끝나는 순서"로 착각하고 반복 가능성을 놓침
- 상관관계와 인과관계를 같은 것으로 혼동
- 회귀·분류·군집의 목적 차이를 구분하지 못함
